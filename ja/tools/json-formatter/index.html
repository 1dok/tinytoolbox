JSON 整形・検証

JSON を読みやすく整形したり、圧縮したり、構文を検証できます。処理はブラウザー内で行われ、入力内容はサーバーに送信されません。

上に JSON を貼り付け、整形・圧縮・検証を選択してください。

プライバシー：ブラウザー標準の JSON パーサーを使用します。アカウントもアップロードも不要です。

使い方

  1. エディターに JSON を貼り付けます。
  2. 「JSON を整形」で読みやすくするか、「圧縮」で不要な空白を削除します。
  3. 「検証」を選択して JSON の構文を確認します。
  4. 「出力をコピー」でエディターの内容をコピーします。
