JSON 格式化与校验

格式化杂乱的 JSON、压缩内容，或检查语法。处理在浏览器中完成，输入内容不会发送到我们的服务器。

请在上方粘贴 JSON，然后选择格式化、压缩或校验。

隐私提示：本工具使用浏览器内置 JSON 解析器，无需账号，也无需上传。

使用方法

  1. 将 JSON 粘贴到编辑框。
  2. 选择“格式化 JSON”以便阅读，或选择“压缩”移除多余空白。
  3. 选择“校验”检查 JSON 语法是否正确。
  4. 点击“复制输出”复制编辑框中的内容。
